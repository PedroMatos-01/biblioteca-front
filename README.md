# Biblioteca Front

Esse é o front-end do meu sistema de biblioteca, feito para o Desafio Front-end 2026/2 da Comp Júnior. Ele é a parte visual do projeto [Sistema de Biblioteca-back](https://github.com/PedroMatos-01/biblioteca-back), então vai consumir a API que eu mesmo criei.

A ideia é a mesma do back: uma versão simplificada do sistema que a biblioteca da UFLA usa. O leitor (aluno) consulta o catálogo, pega livros emprestados e renova. O administrador (bibliotecário) cadastra os livros e controla empréstimos e devoluções.

## Tecnologias

- **React com Vite**: recomendado pelo desafio, e o Vite deixa o ambiente rápido de montar.
- **JavaScript**: é a mesma linguagem do back, o que facilita a integração.
- **React Router e Axios**: vão entrar nas próximas etapas, para as rotas e para as requisições à API.
